## Student Grade Calculator Python.

## project overview
A simple  student grade calculator built with python that calculates
total marks ,percentage, and grade for students.
## Features
1. Add student result
2. View student result
3. Calculate total marks
4. Calcualte percentage
5. Calculate grade
6. Exit program
## Technology used
- Python
## How to run
```Bash
python student_grade_calculator.py
```
